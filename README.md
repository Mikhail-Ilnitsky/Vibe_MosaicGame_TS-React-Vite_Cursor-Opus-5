# Игра-мозаика

Адаптивная браузерная игра-мозаика: выберите картинку, выберите сложность и соберите изображение из перемешанных квадратных фрагментов. Это чистый фронтенд (SPA) — без бэкенда, базы данных и сохранения состояния на сервере.

**Демо:** https://<ваш-логин>.github.io/Vibe_MosaicGame_TS-React-Vite_Cursor-Opus-5/

## Возможности

- **Галерея с локализацией.** Шесть картинок разной ориентации; название показывается при наведении на десктопе и подписью под миниатюрой на смартфоне. Переключатель RU / EN в правом верхнем углу, язык по умолчанию определяется по `navigator.language`.
- **Расчёт сеток сложности.** Меньшая сторона картинки всегда делится на N частей (N от 5 до 11), количество частей по большей стороне подбирается автоматически так, чтобы фрагменты оставались строго квадратными; остаток оригинала обрезается симметрично от центра.
- **Управление двумя способами одновременно.** Клик-клик (первый клик выделяет фрагмент рамкой, второй меняет их местами) и перетаскивание на Pointer Events — одинаково работает мышью и пальцем. Порог перетаскивания — половина стороны плитки: меньше порога это клик, больше — drag.
- **Адаптивное поле.** Пазл всегда целиком помещается в свободную область экрана без прокрутки; размеры задаются в долях доступного места, а не фиксированными пикселями. Картинка меньше доступной области не растягивается крупнее масштаба 1:1.
- **Счётчик ходов.** Ход — это обмен двух фрагментов; счётчик виден во время игры и повторяется в сообщении о победе.
- **Просмотр оригинала.** Кнопка показывает исходное изображение в том же размере и с той же обрезкой краёв, что и собираемый пазл.
- **Анимация победы.** Собранная сетка мигает ярким жёлтым на 500 мс, затем исчезает, оставляя ту же обрезанную картинку, а под ней плавно появляются сообщение «У вас получилось!» и кнопка новой игры.

## Стек

- [React](https://react.dev/) 19.3
- [TypeScript](https://www.typescriptlang.org/) 5.9
- [Vite](https://vite.dev/) 8.3
- [Tailwind CSS](https://tailwindcss.com/) 4.3 (через плагин `@tailwindcss/vite`)
- ESLint 10 с `typescript-eslint`, `eslint-plugin-react-hooks` и `eslint-plugin-react-refresh`

## Происхождение проекта

Исходная версия сгенерирована в Cursor по техническому заданию [`prompts/INITIAL.md`](prompts/INITIAL.md). Подробный контекст проекта — ключевые решения по сетке, CSS-фрагментам, управлению, i18n и деплою — собран в [`.cursor/CONTEXT.md`](.cursor/CONTEXT.md).

## Запуск

```bash
npm install      # установка зависимостей
npm run dev      # дев-сервер Vite на http://localhost:5173
npm run build    # проверка типов (tsc -b) и production-сборка в dist/
npm run preview  # локальный просмотр собранного проекта на http://localhost:4173
npm run lint     # ESLint по всему проекту
npm run typecheck # только проверка типов
```

Локально приложение открывается с корня, без префикса репозитория: в `vite.config.ts` для сборки задан относительный `base: './'`, который одинаково работает и в `npm run preview`, и в подкаталоге GitHub Pages.

## Деплой

Деплой выполняет workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) при пуше в `main` (или вручную через «Run workflow»). В репозитории нужно один раз выбрать **Settings → Pages → Build and deployment → Source: GitHub Actions**.

## Структура

```
src/
├── main.tsx                      # точка входа, монтирование React и провайдер языка
├── App.tsx                       # шапка, переключатель языка и навигация между экранами
├── index.css                     # подключение Tailwind, базовые стили и keyframes анимаций
├── types.ts                      # общие типы: язык, ориентация, картинка
├── data/
│   └── images.ts                 # готовый массив картинок с прямыми ссылками
├── i18n/
│   ├── translations.ts           # словари RU / EN, склонения, определение языка браузера
│   ├── LanguageContext.ts        # контекст с текущим языком и словарём
│   ├── LanguageProvider.tsx      # провайдер языка, синхронизация атрибута lang
│   └── useLanguage.ts            # хук доступа к языку и переводам
├── lib/
│   ├── grid.ts                   # расчёт сетки, обрезки и CSS-фона фрагментов
│   └── shuffle.ts                # перемешивание парными обменами и проверка победы
├── hooks/
│   ├── useImageMeta.ts           # натуральные размеры картинки с кешированием
│   └── useElementSize.ts         # размер элемента через ResizeObserver
└── components/
    ├── LanguageSwitcher.tsx      # переключатель RU / EN
    ├── Gallery.tsx               # галерея миниатюр с локализованными названиями
    ├── DifficultyScreen.tsx      # выбор сложности с предпросмотром сеток
    ├── GameScreen.tsx            # загрузка картинки и расчёт сетки для партии
    ├── PuzzleGame.tsx            # состояние партии: ходы, выделение, победа, оригинал
    ├── MosaicBoard.tsx           # поле мозаики, клик-клик и drag на Pointer Events
    └── Tile.tsx                  # один фрагмент: фон, рамка, состояние перетаскивания
```
